TCA8418 keypad diagnostics

Radio | Screen

GPIO9 SCL, GPIO10 SDA; INT and RST unconnected; I²C address 0x34. Detection is read-only. Scanning is restored on boot only when the isolated 6 × 9 matrix has been explicitly remembered below. Disabling scanning clears that setting.

Connecting...

Matrix scan

Scanning drives selected row/column pins. Enable only if they connect exclusively to isolated passive switches—not to the original Sony controller or another powered circuit. Pin counts use consecutive ROW0 onward and COL0 onward. Unknown wiring: leave scanning off.

Recent press/release events

Rows and columns are zero-based. The last 32 events are retained until reboot; overflow indicates events were lost. A short press of Display Mode (R5–C7) starts a stopped display in Now Playing, then cycles display modes and OFF. A long press changes DIM once while DISPLAY is still held; a short press acts after release.

CHECK (R2–C4) starts a stopped display in Stereo VU. DISPLAY and CHECK restore the brightness from before OFF, initially 1.2% after reboot. Neither button can sense Sony power or buffer /OE: use either start action only after the Sony is powered, the original drivers are isolated and outputs are ready. It does not replace a running scan.

Preset buttons 1–16 briefly show the preset number, then the search animation and connected station name, before returning to the selected mode. An unassigned button shows “Unassigned” without changing station.
